# Assignment 3: Forward Propagation and Backpropagation

## Problem Statement

Implement forward propagation and backpropagation using TensorFlow/Keras. Analyze the effect of different learning rates and the number of epochs on model performance.

## Objective

To understand and implement the forward propagation and backpropagation processes using TensorFlow/Keras and analyze how different learning rates and numbers of epochs affect model performance.

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- TensorFlow
- Keras

## Methodology

1. Prepare the dataset.
2. Build a neural network using TensorFlow/Keras.
3. Implement and understand forward propagation.
4. Implement and understand backpropagation.
5. Train the model using different learning rates.
6. Train the model using different numbers of epochs.
7. Compare the training performance for different configurations.
8. Analyze the effect of learning rate and epochs on model performance.
9. Visualize the results using appropriate graphs.

## Parameters Analyzed

- Learning Rate
- Number of Epochs
- Training Loss
- Validation/Test Performance
- Accuracy

## Files

## Conclusion

The assignment demonstrates forward propagation and backpropagation using TensorFlow/Keras and analyzes how learning rate and the number of epochs influence the performance of a neural network.
