# Assignment 5: RNN, LSTM and GRU for Sequence Classification

## Problem Statement

Implement and compare RNN, LSTM, and GRU models for sequence classification, and analyze their performance using appropriate evaluation metrics.

## Objective

To implement Recurrent Neural Network (RNN), Long Short-Term Memory (LSTM), and Gated Recurrent Unit (GRU) models for sequence classification and compare their performance using suitable evaluation metrics.

## Dataset

A suitable sequence or text classification dataset is used for training and evaluating the models.

## Technologies Used

- Python
- Jupyter Notebook / Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras

## Models Implemented

### 1. Simple RNN

A basic Recurrent Neural Network is implemented to process sequential data and perform classification.

### 2. LSTM

A Long Short-Term Memory network is implemented to capture long-term dependencies in sequential data.

### 3. GRU

A Gated Recurrent Unit network is implemented as a computationally efficient alternative to LSTM for sequence classification.

## Methodology

1. Load and explore the sequence classification dataset.
2. Preprocess the input data.
3. Split the dataset into training and testing sets.
4. Prepare the data for sequential model input.
5. Build and train the RNN model.
6. Build and train the LSTM model.
7. Build and train the GRU model.
8. Evaluate each model on the test dataset.
9. Compare the performance of RNN, LSTM, and GRU.
10. Visualize training and validation performance.

## Evaluation Metrics

The models are compared using appropriate metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Training and Validation Loss

## Performance Comparison

The performance of RNN, LSTM, and GRU models is compared based on classification accuracy, loss, training behavior, and other evaluation metrics.

## Files

- `Assignment_5_DL.ipynb` – Jupyter Notebook containing the implementation, training, evaluation, comparison and results of RNN, LSTM and GRU models.

## Conclusion

RNN, LSTM, and GRU models are implemented for sequence classification and their performance is compared using appropriate evaluation metrics. The comparison helps identify the strengths and effectiveness of each recurrent architecture for sequential data.
