# Assignment 6: Convolutional Neural Network (CNN) for Image Classification

## Problem Statement

Design and implement a Convolutional Neural Network (CNN) for image classification using the Tomato or Soybean disease dataset.

## Objective

To design and implement a CNN model for classifying plant diseases from images and evaluate the performance of the trained model.

## Dataset

The assignment uses either the Tomato Disease Dataset for image classification.

## Technologies Used

- Python
- Jupyter Notebook / Google Colab
- NumPy
- Matplotlib
- TensorFlow
- Keras

## Methodology

1. Load the Tomato or Soybean disease dataset.
2. Explore and preprocess the image data.
3. Resize and normalize the images.
4. Split the dataset into training and testing/validation sets.
5. Design the CNN architecture.
6. Train the CNN model.
7. Evaluate the model on test data.
8. Analyze the classification performance.
9. Visualize training and validation accuracy and loss.

## CNN Architecture

The CNN consists of appropriate layers such as:

- Convolutional Layers
- ReLU Activation
- Max Pooling Layers
- Flatten Layer
- Fully Connected (Dense) Layers
- Output Layer

## Evaluation

The model performance is evaluated using:

- Training Accuracy
- Validation Accuracy
- Test Accuracy
- Training and Validation Loss
- Classification Results

## Files

- `Assignment_6_DL.ipynb` – Jupyter Notebook containing the complete CNN implementation, training, evaluation and results.

## Conclusion

The CNN model is implemented for plant disease image classification. The model's performance is analyzed using accuracy and loss measurements to determine its effectiveness in classifying the selected plant diseases.
