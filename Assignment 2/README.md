# Assignment 2: Multilayer Perceptron (MLP) Classification

## Problem Statement

Design and implement a Multilayer Perceptron (MLP) for classification of the Iris or Wine dataset, and evaluate its performance using accuracy and a confusion matrix.

## Objective

To design and implement a Multilayer Perceptron (MLP) neural network for classification and evaluate its performance using classification accuracy and a confusion matrix.

## Dataset

The assignment uses either the Iris dataset for multiclass classification.

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Methodology

1. Load the Iris or Wine dataset.
2. Explore and preprocess the dataset.
3. Split the dataset into training and testing sets.
4. Build an MLP classification model.
5. Train the model using the training data.
6. Make predictions on the test data.
7. Calculate classification accuracy.
8. Generate and visualize the confusion matrix.
9. Analyze the model performance.

## Evaluation Metrics

- Accuracy
- Confusion Matrix

## Files

- `Assignment_2_DL.ipynb` – Jupyter Notebook containing the complete implementation, model training, evaluation and results.

## Conclusion

The MLP model is implemented for multiclass classification and its performance is evaluated using accuracy and a confusion matrix.
